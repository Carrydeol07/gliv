# 02_SCOPE.md

> Version: 2.0
> Status: Locked Foundation

## Version 1 Goals

GLIV v1 focuses on solving one problem exceptionally well: maintaining a beautiful, long-term personal media library.

## Included

### Library

- Personal library
- Original order
- Grid, Shelf, and List views
- Fast editing
- Multi-format Titles
  - Anime
  - Manga
  - Manhwa
  - Manhua
  - Novel
- Ratings
- Favorites

### Collections

Built-in:

- Favorites
- Plan to Watch / Read

Custom collections.

Filtering:

- Media type
- Genres
- Personal tags
- Rating

### Discover

- Universal Search
- Seasonal Anime
- Upcoming Releases
- Upcoming Adaptations
- Powerful filtering
- Manual Title creation

### Updates

Personal updates only:

- New episodes
- New chapters
- Hiatus / Return
- New season announcements
- Trailer releases
- Official English releases

### Series Pages

- Progress
- Progress Override
- Notes
- Rating
- Favorite
- Contributors
- Connections
- Availability
- Metadata

## Out of Scope (v1)

- Social features
- Cloud sync
- Achievements
- Reviews
- Chat
- Statistics dashboards
- AI recommendations
- Mobile app

## Success

GLIV succeeds when it permanently replaces the user's DOCX workflow while remaining fast, reliable, and enjoyable to use every day.
