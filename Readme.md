# GLIV

GLIV is a local-first desktop application for managing a personal library of anime, manga, manhwa, manhua, light novels, and web novels.

## Technology Stack

- Electron
    
- React
    
- TypeScript
    
- SQLite
    

## Project Principles

- Local-first
    
- Personal data is never overwritten
    
- Documentation is the source of truth
    
- Architecture before implementation
    
- Build one module at a time
